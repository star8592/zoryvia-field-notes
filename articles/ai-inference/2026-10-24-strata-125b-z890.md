# RTX 5070 Ti + 96GB 内存部署 Strata 125B：一次真实安装实录

> 状态：**IN_PROGRESS（部署进行中）** · 日期：2026-10-24。本文不是已实现的 125B 性能测评；下载、加载与速度验证未完成时，不做成功宣称。

## 为什么做这个实验

目标是在消费级台式机上运行 125B 参数的 MoE 大模型，以本地 AI 承接商品客服问答。手机端 Android APP 负责监听、理解消息上下文与操作原生聊天界面，AI 推理端在 Linux 电脑上；发货机器人与客服机器人在业务职责上隔离，支付/履约状态必须由可信订单状态核验。

Strata 的 MoE 专家动态调度技术值得验证，但“作者机器上快”不等于“自己的设备上快”，因此记录了实际安装和测试回执。

## 机器及 SSD 环境（实机确认）

| 项目 | 实际配置 |
|---|---|
| GPU | RTX 5070 Ti，约 16GB 显存 |
| 内存 | 标称 96GB，Linux 显示 91GiB |
| Linux | Ubuntu 26.04.1 LTS |
| Data 盘 | Samsung 990 EVO Plus 1TB NVMe SSD，ext4 |
| Data 盘容量 | 文件系统显示 916G，安装前可用约 555G |
| NVIDIA 驱动 | 615.71.09 |

安装时发现 Data SSD 已存放 CI、视频和虚拟机项目，约 315G 已用。**我们没有删除这些可能仍被使用的数据**，而是创建独立目录存放 Strata 及权重文件。SSD 权重加载与操作系统现有任务相互隔离。

## 第一个问题：已有 llama.cpp 二进制缺共享库

检查系统时，旧 `llama-server` 提示缺少 `libllama-server-impl.so`。我们没有为了 Strata 项目直接修改系统共享库、重装全局 CUDA 或调整现有驱动，因为那个二进制的状态并不代表 Strata 有问题。另行部署，避免污染其他项目。

## 第二个问题：Git sparse-checkout 的指定方法

拉取 Strata 源码时，最初向 `git sparse-checkout set` 传入多个 Markdown 文件路径，cone 模式下返回退出码 128。改为直接指定目录 `docs` 后取回文档成功。这类工具边角问题很容易被写教程时忽略，却经常拖慢真实安装。

## 安装实际回执

1. 从官方 GitHub Releases **下载并先审查** `install.sh`，没有直接使用 `curl | sh`。
2. 安装器 SHA-256 为 `73a3e0cbd8f2f00e1f26a304c1f8f498afdf9be3a4a9f58c83fa5ffdb6642780`（仅对应本次下载的文件）。
3. 通过官方支持的 `STRATA_DATA_DIR` 与 `STRATA_BIN_DIR` 参数指定 Data SSD 安装路径，而不是写进用户主目录。
4. 安装 CLI `strata 0.2.4.1`（Terminal build `0.1.49.1`），安装器返回 `Checksum ok` 和 `Signature ok`。
5. 调用 `strata launch --plan` 检查 Qwen3.8-Flash-Next `IQ3_S`，设置 `32k` 上下文、`vision off`、单并发、`access local`；预检给出约 **83.6 GB** 模型权重和 **5.2 GB** 加速层，合计约 88.8GB 下载计划。
6. 单独下载 CUDA 13 推理引擎 `0.1.48`（约 578MiB），经过签名、逐文件校验和启动测试，已成功激活。
7. 模型文件正在下载时，只能写“下载中”，不能写“125B 成功推理”。

执行命令示例（请按本机路径调整）：

```bash
STRATA_DATA_DIR=/path/to/ssd/strata-runtime \
STRATA_BIN_DIR=/path/to/ssd/strata-bin \
sh ./install.sh

/path/to/ssd/strata-bin/strata launch --plan \
  --family qwen --model iq3_s \
  --data-dir /path/to/ssd/models --context 32k \
  --vision off --parallel 1 --port 18090 \
  --access local --output json
```

默认将模型 API 仅绑定本机环回接口。给其他设备调用时，需要先设计认证和受控网络，不能把无鉴权端口直接开放到公网。

## 与客服应用关系

此前在同一主机通过 Ollama 运行较小的 Qwen3.8 9B，禁用思考输出后，一个模拟的中文售前问题生成正式答复耗时约 **2.88 秒**。这一数值来自 **9B + Ollama**，**不能冒充 Strata 125B 的性能**。

预计模型加载成功后测试：真实首 token 延迟、输出 tokens/s、显存和系统内存占用、30 条客服样题的正确性、重复提问的稳定性，以及咨询/付款/发货意图分流。
