## 资料分层

- **实战文章**（Field notes）：讲决策、意外、定位、修复、回归、局限。
- **可复现教程**（Tutorials）：在实机中通过完整步骤后，才从实战文章升级而来。
- **脚本工具**（Scripts）：只收敛经过检查、无需私有账号/密钥、可复用的小工具。
- **案例证据**（Evidence）：仅展示可公开的简化测试记录或可信来源；原始客户数据留在私有环境。
